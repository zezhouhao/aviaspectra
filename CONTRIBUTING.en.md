# Contributing

[中文](CONTRIBUTING.md)


Issues and pull requests are welcome in Chinese or English. Read [AGENTS.md](AGENTS.md) and [development](docs/DEVELOPMENT.en.md) before changing code.

Describe the concrete problem, resulting behaviour, verification and test environment. Keep the UI compact rather than filling previews with engineering diagnostics. Changes to zoom, selection or inference should cover absolute coordinates, task cancellation and return-to-whole behaviour.

Do not commit model weights, runtime libraries, build caches, compiled apps, real recordings, private paths or credentials. New dependencies require official sources, versions, hashes and licenses. Do not bypass sandboxing or disable system security to fix installation.

Update matching Chinese and English documentation, diagrams, release notes and templates together. Avoid unqualified performance promises. The app UI remains Chinese unless separately implemented and tested in other languages.

Original contributions use MIT; third-party materials keep their own terms. The code license does not grant commercial use of BirdNET models.
