# AviaSpectra 1.0.1

[中文](RELEASE_NOTES_v1.0.1.md)

Species candidates now occupy fixed rows above the spectrogram, with larger common/scientific names and dedicated eBird buttons. The UI uses “置信度” (confidence); numerical values and inference are unchanged.

The Finder Quick Look host may refuse browser launches. If prompted, choose Copy link and paste it into your browser. Direct eBird opening has been verified in the standalone app.

The installer backs up the previous app. Existing source users should update the source, run `bash scripts/setup.sh`, close the old app and preview windows, then reopen the new version. New users should follow [INSTALL](INSTALL.en.md).

Six management checks and the full native smoke suite passed. Finder verification covered the new rows, confidence labels and autoplay. See [VALIDATION](VALIDATION.en.md) for scope and outstanding checks.
