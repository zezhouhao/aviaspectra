# AviaSpectra 1.0.1

[English](RELEASE_NOTES_v1.0.1.en.md)

物种候选移到声谱图上方的固定信息栏，多候选分行显示，中文名和拉丁名字号增大；eBird 使用独立按钮。界面统一使用“置信度”，数值和推断算法不变。

Finder 快速预览宿主可能拒绝浏览器跳转；此时点击“复制链接”，再粘贴到浏览器。独立应用已验证可直接打开 eBird。

本机安装更新会保留旧应用备份。已有源码用户更新后重新执行 `bash scripts/setup.sh`，关闭旧应用和预览窗口，再打开新版。新用户见 [安装指南](INSTALL.md)。

6 项管理检查、完整原生 smoke 测试通过；Finder 已核验新版固定栏、置信度和自动播放。完整范围与未验收项目见 [验证记录](VALIDATION.md)。
