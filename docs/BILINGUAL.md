# 中英文发布原则

[English](BILINGUAL.en.md)


适用于整个 GitHub 项目的公开介绍，不只是首页。

- README.md 为中文首页，README.en.md 为英文首页；醒目提供互相切换的入口。
- 功能、安装、AI安装、操作、排错、验证、开发、上传、专题目录、贡献与更新日志分别维护中英文对应页；同一改动同步更新。
- 图示提供中文和英文版本，标题、说明、替代文字与语言对应；实际截图可保留中文界面，但配两种语言的说明。
- Release 标题/正文、About 简介、Issue 模板与对外提交说明使用双语。工程标识、命令、路径无需翻译。
- 速度、兼容性、许可、隐私与已验证范围在两种语言中保持一致。速度观察不得升级为所有设备/音频的保证。
- MIT、第三方许可证、上游版权头与原始绘图提示词保留原文；提供双语解释，但不改写法律原文或来源记录。
- GitHub 文档双语不等于应用双语。当前应用界面为中文；界面本地化须另行实现和测试。
- 发布前逐页检查语言入口、相对链接、配图、限制说明和模板，不能让英文入口默认跳回中文安装指南。
