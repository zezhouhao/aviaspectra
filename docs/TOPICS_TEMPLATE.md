# 未来专题目录示例

[English](TOPICS_TEMPLATE.en.md)


当有第二个项目时，可创建 `ai-projects` 仓库，用以下内容作为首页基础。将“你的用户名”替换为实际 GitHub 用户名；不要把这些示例链接误当作已经发布的项目。

```markdown
# 我的 AI 实践项目

记录使用 AI 工具完成的小应用、研究工具与可复用流程。

## 小应用开发与部署

| 项目 | 用途 | 系统 | 状态 |
|---|---|---|---|
| [AviaSpectra](https://github.com/你的用户名/aviaspectra) | 空格预览鸟鸣声谱与本地识别 | macOS / Apple Silicon | 首版源码分享 |

## 如何使用

进入具体项目阅读 README。每个项目独立维护安装方法、适用环境、许可和问题反馈。
```

每个独立应用建议有自己的仓库，避免一个专题的更新影响另一个。目录仓库只负责导航，不重复存放全部源码。
