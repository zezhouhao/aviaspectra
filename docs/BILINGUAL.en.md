# Bilingual publishing policy

[中文](BILINGUAL.md)


This applies to the whole public GitHub project, not just the homepage.

- README.md is the Chinese homepage and README.en.md the English homepage, with prominent reciprocal links.
- Maintain matching Chinese/English feature, installation, AI setup, usage, troubleshooting, validation, development, upload, topic-index, contribution and changelog pages. Update both with each relevant change.
- Provide diagrams in both languages with matching titles, captions and alt text. Real screenshots may retain the Chinese UI but need bilingual explanations.
- Use bilingual Release titles/bodies, About descriptions, Issue templates and public commit descriptions. Identifiers, commands and paths are not translated.
- Keep speed claims, compatibility, licensing, privacy and validation scope consistent. Observations must not become universal performance promises.
- Preserve MIT/third-party license texts, upstream copyright headers and original image prompts verbatim. Add bilingual explanations without rewriting legal texts or provenance.
- Bilingual GitHub documentation does not mean a bilingual app. The current UI is Chinese; app localization requires separate implementation and testing.
- Before publishing, check every language link, relative link, image, limitation and template. English installation links must lead to English instructions.
