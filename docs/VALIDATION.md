```sh
python3 tests/smoke.py
```

## 速度表述的依据与边界

此前开发机的短音频演示中，界面显示过约0.1–0.6秒的分析耗时。这是少量已观察到的读数，不是正式性能研究；没有控制冷启动/缓存条件，也不是从按空格开始的统一端到端计时。首次模型加载、缓存状态、硬件和音频长度都会影响实际等待时间。不得据此宣称每条录音都在一秒内完成，或整个录音库在该时间内处理完毕。
