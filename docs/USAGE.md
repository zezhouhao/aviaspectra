# 使用方法

[English](USAGE.en.md)


Finder 选中 MP3/WAV 后按空格。独立应用也可打开文件（Command+O）。默认自动播放，可取消底部勾选。

## 看声谱与播放

横轴为原音频时间（秒），纵轴为频率（kHz），亮色表示更强的频谱幅度。上方是波形，白线为播放位置。点击图面或拖动进度条跳转。独立应用中空格切换播放/暂停；Finder 中空格通常关闭快速预览。

## 缩放与画框

滚轮、两指上下滚动和捏合以鼠标所在位置等比例缩放两个轴。横向滚动或 Shift+滚动平移时间；Option+滚动平移时间/频率。双击或点击倍率按钮恢复视图。放大重新计算局部时间范围的声谱，不改变 FFT 的原始频率分辨率。

左键在声谱上拖出矩形，黄色标签显示原始时间和频率。点击“识别选框”后，按所选时间裁剪、进行带通滤波，再交给模型；不是只识别当前屏幕可见区域。过窄频带可能去掉谐波；少于3秒的音频会补零。

“清除”只移除框线；“返回整体”清除框线、恢复完整视图和整段候选。恢复整段保留播放进度及地点设置，不重开文件。

## 候选与链接

浮动卡片显示最多3个候选，可拖动背景避开图像；更多候选通过菜单切换。中文名、拉丁名、评分和时间条颜色对应。点击拉丁名打开 XC，点击 eBird 打开该物种页。分类名与网站不同步时链接可能失效，不代表音频鉴定结论。

时间条合并同一物种的重叠3秒识别窗口；并不精确标出声音起止或对应频带。多个候选可能是真实混合鸟声，也可能是误判。

## 地点

点击“地点：全球”选择城市预设或填写录音地点经纬度。采用全年先验，尚未提供月份筛选。经度东为正、西为负，纬度北为正、南为负。不读取设备定位。独立应用和预览扩展的偏好存储隔离，可能需要分别设置；更换来源地区时注意核对。

## 数据与隐私

音频不会被本工具改写或发送。首次安装下载模型；推断离线运行，缓存只包含内容哈希对应的候选结果。点击物种链接会将物种名称或物种代码交给浏览器/对应网站，不发送音频。缓存位于各自应用/扩展的系统缓存目录下 `AviaSpectra/`。
