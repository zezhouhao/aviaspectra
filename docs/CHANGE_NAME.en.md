# Project name

[中文](CHANGE_NAME.md)


On 2026-11-13 the public name became **AviaSpectra (谱羽)**. BirdScope was an early working name and is no longer the public project name.

App/repository names, installation paths, bundle identifiers and documentation were updated. The author's installed prototype was not modified. Its old identifier remains only for migration/troubleshooting. The text-free icon is reused unchanged; the original prompt is preserved in [icon provenance](../assets/ICON_PROMPT.md).
