# 自带鸟鸣体验 / Included bird recordings

[English](README.en.md)

这些是真实鸟类录音，随项目 ZIP 一起提供，**无需另行下载音频**。先完成应用安装，再在 Finder 选中下列 MP3 或 WAV，按空格；独立应用也可点击“打开其它音频…”选择此文件夹中的文件。

| 音频 | 来源标注的主物种 | 时长 | 录音者 |
|---|---|---:|---|
| [XC24828.mp3](XC24828.mp3) | 小嘴乌鸦 · Carrion Crow · *Corvus corone* | 约 8.7 秒 | Sander Pieterse |
| [XC473244.mp3](XC473244.mp3) | 赭红尾鸲 · Black Redstart · *Phoenicurus ochruros* | 约 69.6 秒 | Marie-Lan Taÿ Pamart |
| [XC539061.mp3](XC539061.mp3) | 原鸽 · Rock Dove · *Columba livia* | 约 38.7 秒 | Marie-Lan Taÿ Pamart |
| [XC24828.wav](XC24828.wav) | 与第一条相同，用于体验 WAV 格式 | 约 8.7 秒 | Sander Pieterse |

建议先听最短的小嘴乌鸦叫声，再听赭红尾鸲鸣唱与原鸽咕咕声，观察不同时间和频率结构；试试等比例缩放、画框识别和“返回整体”。地点未知时保留“全球”。这些物种名是来源的主物种标注，录音也可能含背景声音；模型候选与评分仍需复听核实，不保证与标注完全一致。
