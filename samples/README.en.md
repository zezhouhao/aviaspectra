# Included bird recordings

[中文](README.md)

These are real bird recordings included in the project ZIP. **No separate audio download is required.** Install the app, select an MP3 or WAV in Finder and press Space, or choose a file here with the standalone app's **打开其它音频…** (Open another audio) button.

| Audio | Main species labelled by the source | Duration | Recordist |
|---|---|---:|---|
| [XC24828.mp3](XC24828.mp3) | Carrion Crow · *Corvus corone* | ~8.7 s | Sander Pieterse |
| [XC473244.mp3](XC473244.mp3) | Black Redstart · *Phoenicurus ochruros* | ~69.6 s | Marie-Lan Taÿ Pamart |
| [XC539061.mp3](XC539061.mp3) | Rock Dove · *Columba livia* | ~38.7 s | Marie-Lan Taÿ Pamart |
| [XC24828.wav](XC24828.wav) | Same recording as the first row, for trying WAV | ~8.7 s | Sander Pieterse |

Start with the shortest crow call, then compare the redstart song and pigeon calls. Try equal-axis zoom, drawing a selection, re-identifying it and returning to the whole recording. Leave Location on Global when unknown. Species names are the sources' main-species labels; background sounds may also occur. Model candidates and scores require listening and verification and need not match these labels.
